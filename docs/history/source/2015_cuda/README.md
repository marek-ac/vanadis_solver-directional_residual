# Historical CUDA implementation

This directory contains an early CUDA implementation of the Vanadis
Element-by-Element linear solver.

The source is believed to date from approximately 2015, based on the author's
archived files and preserved filesystem metadata. The date has not been
independently verified by a cryptographic timestamp or contemporaneous
version-control record.

The historical CUDA source originally depended on the NVIDIA helper headers
`book.h` and `lock.h`. These third-party files are not redistributed in this
repository. Only the Vanadis CUDA source is preserved here.

The source is retained as a historical development artifact and is not the
current production implementation.
