# Vanadis Solver — Key Source Files

Current development release: v2026.3.0

Reference release for the CMAS 2026 study: v2026.2.1

## Purpose

This file lists the most important source files provided directly in the
Vanadis GitHub repository.

The selected source files are intended to help users and developers inspect
the core numerical implementation of Vanadis, including the FEM solver,
Directional Residual stabilization, nonlinear reaction handling, time-dependent
source handling, OpenMP parallelization, and CUDA Element-by-Element solver.

The files stored in the repository are not a complete copy of the release
package. The complete Vanadis distribution is available in the corresponding
ZIP archive in the GitHub Releases section.

## Vanadis v2026.3.0

Selected source files for the current development release are located in:

src_v2026_3_0\

The v2026.3.0 source code includes the implementation of:

* three-dimensional HEX8 finite elements
* Directional Residual (DR) stabilization
* Element-by-Element matrix operations
* OpenMP CPU assembly
* CPU and CUDA DBCG iterative solution
* diagonal preconditioning
* CUDA Element-by-Element matrix-vector operations
* CUDA graph-coloring and atomic execution variants
* nonlinear concentration-dependent reaction/decay coefficient P(S)
* Picard iteration for the nonlinear problem
* generalized time-dependent source handling Q(t)
* implicit transient time integration
* Dirichlet and flux-type boundary conditions
* buffered output and post-processing support

## Main solver

The main Vanadis source contains the FEM formulation, Directional Residual
stabilization, transient solution procedure, boundary conditions, nonlinear
P(S) treatment, Q(t) source handling, Picard iteration, OpenMP assembly, and
interface to the iterative CPU/CUDA solver.

## CUDA solver

The CUDA source files contain the GPU implementation of the Element-by-Element
DBCG solver.

Two principal GPU execution strategies are provided:

1. Atomic Element-by-Element implementation

   Element contributions to shared global nodes are accumulated using CUDA
   atomic operations.

2. Graph-coloring Element-by-Element implementation

   HEX8 elements are divided into independent color groups so that elements
   processed within the same color do not share nodes. This allows the main
   matrix-vector operations to be executed without atomic updates within each
   color.

## Nonlinear P(S) and time-dependent Q(t)

Vanadis v2026.3.0 introduces a nonlinear concentration-dependent
reaction/decay coefficient P(S).

The resulting nonlinear problem is solved using Picard iteration within each
time step while preserving the existing Directional Residual and
Element-by-Element architecture.

The source-term implementation has also been generalized to support
time-dependent emissions Q(t), allowing constant, switched, pulsed, or other
temporally varying source profiles.

## CMAS 2026 reference release

Vanadis v2026.2.1 remains the final reference release for the CMAS 2026 study.

The nonlinear P(S) formulation and generalized time-dependent Q(t) source
handling introduced in v2026.3.0 were developed after the CMAS 2026 reference
version and were not part of the CMAS 2026 study.
