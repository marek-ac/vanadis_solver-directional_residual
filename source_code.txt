# Vanadis Solver — Key Source Files

Current development line: v2026.3.1
Status: development baseline, not yet the final v3.1 release

Latest packaged release: v2026.3.0

Reference release for the CMAS 2026 study: v2026.2.1

## Purpose

This file lists the most important source files provided directly in the
Vanadis GitHub repository.

The selected source files are intended to help users and developers inspect
the core numerical implementation of Vanadis, including the FEM solver,
Directional Residual stabilization, nonlinear reaction handling, time-dependent
source handling, terrain-following geometry, locally evaluated physical fields,
higher-order Gauss integration, mass-balance diagnostics, OpenMP parallelization,
and the CUDA Element-by-Element solver.

Published release packages are available through the GitHub Releases section.
The current v2026.3.1 development baseline is provided directly in the repository.

## Vanadis v2026.3.1 — current development baseline

The current development baseline is located in:

src_v2026_3_1\

The v2026.3.1 source code includes the implementation of:

* three-dimensional transient convection-diffusion-reaction transport
* HEX8 finite elements
* Directional Residual (DR) stabilization
* Element-by-Element matrix operations
* OpenMP CPU assembly
* CPU and CUDA DBCG iterative solution
* diagonal preconditioning
* CUDA Element-by-Element matrix-vector operations
* CUDA graph-coloring and non-coloring execution variants
* nonlinear concentration-dependent reaction/decay coefficient P(S)
* Picard iteration for the nonlinear problem
* generalized time-dependent source handling Q(t)
* locally evaluated physical fields v(x,y,z,t), K(x,y,z,t), and alpha(x,y,z,t)
* terrain-following meshes
* terrain-consistent test velocity fields
* 27-point (3 x 3 x 3) Gauss integration for HEX8 volume terms
* 9-point (3 x 3) Gauss integration for Q4 boundary terms
* full mass-balance diagnostics
* implicit transient time integration
* Dirichlet and flux-type boundary conditions
* buffered output and post-processing support

The v2026.3.1 directory also contains documentation and reproducible validation
material for the current terrain-following development baseline.

## Main solver

The main Vanadis source for the current development line is:

src_v2026_3_1\VANADIS.FOR

It contains the FEM formulation, Directional Residual stabilization, transient
solution procedure, boundary conditions, nonlinear P(S) treatment, Q(t) source
handling, Picard iteration, terrain-following geometry support, locally evaluated
physical fields, higher-order Gauss integration, mass-balance diagnostics,
OpenMP assembly, and the interface to the iterative CPU/CUDA solver.

## CUDA solver

The current default CUDA DBCG implementation is:

src_v2026_3_1\cudatest.cu

Additional comparison versions are provided:

* cudatest_color.cu — coloring-enabled version
* cudatest_no_color.cu — non-coloring reference version

The CUDA sources implement the Element-by-Element DBCG solver and support GPU
processing strategies based on independent element groups and direct shared-node
updates.

## Build and configuration

The principal build and runtime configuration files for the current development
baseline are:

src_v2026_3_1\Makefile
src_v2026_3_1\vanadis.cfg

## Documentation and validation

Documentation for the current v2026.3.1 development baseline is located in:

src_v2026_3_1\DOC\

Validation material is located in:

src_v2026_3_1\validation\

The current baseline includes checks for flat-terrain regression,
terrain-following mesh generation, terrain-consistent velocity treatment,
full mass balance, nonlinear P(S), CUDA DBCG operation, and GPU coloring.

Further validation is planned for stronger terrain deformation and comparison
of lower- and higher-order volume integration on warped HEX8 meshes.

## Vanadis v2026.3.0 — packaged release

Vanadis v2026.3.0 introduced:

* nonlinear concentration-dependent reaction/decay coefficient P(S)
* Picard iteration within each time step
* generalized time-dependent source handling Q(t)

The full packaged v2026.3.0 distribution is available from:

https://github.com/marek-ac/vanadis_solver-directional_residual/releases/tag/v2026.3.0

The release ZIP archive contains the complete source set, directory structure,
configuration files, documentation, input datasets, and sample results.

The corresponding repository snapshot is located in:

src_v2026_3_0\

## CMAS 2026 reference release

Vanadis v2026.2.1 remains the final reference release for the CMAS 2026 study.

The nonlinear P(S) formulation and generalized time-dependent Q(t) source
handling introduced in v2026.3.0, as well as the terrain-following and extended
integration developments in v2026.3.1, were developed after the CMAS 2026
reference version and were not part of the CMAS 2026 study.

The CMAS 2026 reference release is available from:

https://github.com/marek-ac/vanadis_solver-directional_residual/releases/tag/v2026.2.1
